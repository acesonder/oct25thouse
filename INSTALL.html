🏥 Healthcare Management System

HIPAA-Compliant Healthcare Portal - Setup Instructions

📋 Quick Info: This system provides a complete healthcare management solution with patient portals, staff management, instant messaging, and comprehensive admin controls.

🚀 Installation Steps

Step 1: Database Setup

Import the database schema to create all necessary tables.

  1. Open phpMyAdmin in your browser
  2. Click on "Import" in the top navigation
  3. Choose file: database/schema.sql
  4. Click "Go" to import
✓ This creates the healthcare_system database with all tables and a default admin account.

Step 2: Configure Database Connection

Update database credentials in the configuration file.

  1. Open config/config.php
  2. Update the following constants:
define('DB_HOST', 'localhost');
define('DB_NAME', 'healthcare_system');
define('DB_USER', 'your_username');
define('DB_PASS', 'your_password');

Step 3: Set Directory Permissions

Ensure the web server can write to upload directories.

chmod 755 uploads/
chmod 755 sessions/
chmod 755 tmp/

Step 4: Configure Web Server

Point your web server to the project directory.

  • For Apache: Set DocumentRoot to the project folder
  • Enable mod_rewrite if using Apache
  • Ensure PHP extensions are enabled: PDO, PDO_MySQL, session

Step 5: Access the Application

Open your browser and navigate to:

http://localhost/

or your configured server URL.

📱 User Portals

Client Portal

  • Self-registration with auto-generated User ID
  • Instant account activation
  • Access to messaging and notifications
  • Profile management and settings

Staff Portal

  • Requires admin approval
  • Client management capabilities
  • Communication tools
  • Approval workflow for service providers

Service Provider Portal

  • Requires admin approval
  • Service offering management
  • Client communication
  • Specialized dashboard

Admin Portal

  • Access via /admin/admin.php (passcode: 079777)
  • Create and manage all account types

  • View system statistics and audit logs

🛡️ Security Best Practices

For Production Deployment:
  • Enable HTTPS and update session.cookie_secure to 1
  • Set display_errors to 0 in config.php
  • Use strong database passwords
  • Regularly backup the database
  • Review audit logs periodically
  • Keep PHP and MySQL updated
